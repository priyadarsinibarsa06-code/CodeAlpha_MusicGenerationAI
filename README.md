# Music Generation with AI

This project is developed for the CodeAlpha Artificial Intelligence Internship.

## 📌 Project Description
This AI project generates random music notes and creates a MIDI music file.

## 🚀 Features
- Generate random music notes
- Create MIDI music file
- Download generated music

## 🛠️ Technologies Used
- Python
- Streamlit
- music21

## ▶️ How to Run the Project

1. Install required libraries:
pip install streamlit music21

2. Run the project:
streamlit run app.py
